# Documentation

## Transport App Implementation Documentation

**File:** `Transport_App_Implementation_Documentation.md`

This document describes how the transport app implements:
- Adding schools and locations in the admin web
- Sending notifications to parents (ride start/ride end)
- Route deviation detection and alerts

### Export to PDF

You can convert the Markdown file to PDF in any of these ways:

1. **VS Code / Cursor:** Install the "Markdown PDF" extension, open the `.md` file, right-click in the editor → "Markdown PDF: Export (pdf)".

2. **Browser:** Open the `.md` file in a Markdown viewer (e.g. GitHub), then use Print → Save as PDF.

3. **Pandoc (if installed):**  
   `pandoc Transport_App_Implementation_Documentation.md -o Transport_App_Implementation_Documentation.pdf`

4. **Google Docs:** Copy the markdown content, paste into Google Docs, then File → Download → PDF.
